# Anya | Voice-to-Text Telegram Bot

Anya is a small bot that turns voice messages into text. It helps you get text from voice fast.

![Anya Bot Demo](docs/assets/demo.png)

Simple features

- Send a voice message and get text.
- Works on small servers and Raspberry Pi.
- Easy to run and manage.

Quick start

1. Create a Python 3 virtual environment and install requirements.
2. Create a .env file with your Telegram token and API keys.
3. Run migrations: `python manage.py migrate`.
4. Start the bot or use systemd for auto start.

Admin panel
